# Backend API Modifications & Integration Requirements

## 1. Pydantic Request Schema Dual-Aliasing (`camelCase` & `snake_case`)

### Problem
Web clients transmit payloads with `camelCase` keys (`imageUrl`, `aspectRatio`, `customBackdrop`, `productName`, `targetRatio`, `userId`, `scaleFactor`), while standard schemas enforce `snake_case`. This results in HTTP 422 Unprocessable Entity errors.

### Solution
In FastAPI request models under `app/schemas/`, enable dual-aliasing so both casing styles are accepted.

```python
from pydantic import BaseModel, ConfigDict
from pydantic.alias_generators import to_camel

class BaseSchema(BaseModel):
    model_config = ConfigDict(
        alias_generator=to_camel,
        populate_by_name=True,  # Accepts both snake_case and camelCase
        extra="ignore"
    )
```

For explicit field mapping:
```python
class ToolRequest(BaseModel):
    image_url: str = Field(..., alias="imageUrl")
    custom_backdrop: Optional[str] = Field(None, alias="customBackdrop")
    aspect_ratio: Optional[str] = Field("1:1", alias="aspectRatio")
    product_name: Optional[str] = Field(None, alias="productName")
    target_ratio: Optional[str] = Field(None, alias="targetRatio")
    scale: Optional[int] = Field(2, alias="scaleFactor")

    model_config = ConfigDict(populate_by_name=True)
```

## 2. CORS & Tunnel Preflight Headers Configuration

### Problem
Browser preflight (`OPTIONS`) requests require explicit header whitelisting for tunnel domains (`loca.lt`, `ngrok`).

### Solution
In `app/main.py`, configure `CORSMiddleware` to allow credentials, all standard methods, and required tunnel bypass headers:

```python
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=[
        "Authorization",
        "Content-Type",
        "Bypass-Tunnel-Reminder",
        "ngrok-skip-browser-warning",
        "*",
    ],
    expose_headers=["*"],
)
```

## 3. Supabase RPC Permissions for Wallet Ledger

### Problem
Under Row-Level Security (RLS), direct `UPDATE` / `INSERT` on `public.wallets` is restricted. Calls to `deduct_user_credits` and `refund_user_credits` require explicit execution permissions.

### Solution
Run the following SQL migration:

```sql
ALTER FUNCTION public.deduct_user_credits(UUID, NUMERIC, TEXT, TEXT) SECURITY DEFINER;
ALTER FUNCTION public.refund_user_credits(UUID, NUMERIC, TEXT, TEXT) SECURITY DEFINER;

GRANT EXECUTE ON FUNCTION public.deduct_user_credits(UUID, NUMERIC, TEXT, TEXT) TO authenticated, anon, service_role;
GRANT EXECUTE ON FUNCTION public.refund_user_credits(UUID, NUMERIC, TEXT, TEXT) TO authenticated, anon, service_role;
```

## 4. Route Aliasing Consistency

### Problem
Endpoints must be accessible through both direct `/api/v1/...` and legacy `/api/v1/prompt-engineering/...` prefixes to prevent 404 route mismatches.

### Solution
Mount routers under both path prefixes in `app/main.py`:

```python
# Standard prefix
app.include_router(tools_router, prefix="/api/v1/prompt-engineering/tools", tags=["Tools"])
app.include_router(vision_router, prefix="/api/v1/prompt-engineering", tags=["Vision"])
app.include_router(generation_router, prefix="/api/v1/prompt-engineering/generation", tags=["Generation"])

# Direct root aliases
app.include_router(tools_router, prefix="/api/v1/tools", tags=["Tools"])
app.include_router(vision_router, prefix="/api/v1", tags=["Vision"])
app.include_router(generation_router, prefix="/api/v1/generation", tags=["Generation"])
```

## 5. Tool Response URL Parity Contract

### Problem
Frontend consumers check for `output_url`, `image_url`, and `url`. Missing any of these fields causes undefined asset references.

### Solution
Ensure all image-generation and tool endpoints return all standard URL keys:

```python
return {
    "task_id": task_id,
    "status": "completed",
    "output_url": public_cdn_url,
    "image_url": public_cdn_url,
    "url": public_cdn_url,
    "cutout_url": public_cdn_url,  # For background remover
    "tokens_consumed": 0,
    "credits_deducted": 0,
    "is_free": True,
}
```

## 6. Prompt Copilot `session_id` Schema Optionality

### Problem
`POST /api/v1/prompt-engineering/chat-delta` rejects requests with HTTP 422 if `session_id` is required and not yet generated by the client.

### Solution
Make `session_id` optional with an automatic fallback:

```python
class PromptDeltaRequest(BaseModel):
    base_prompt: str
    user_instruction: str
    session_id: Optional[str] = Field(default=None)
    turn_count: int = Field(default=1)
    ai_model: Optional[str] = None
```

In the endpoint handler:
```python
if not request.session_id:
    request.session_id = f"copilot_{uuid4().hex[:12]}"
```
